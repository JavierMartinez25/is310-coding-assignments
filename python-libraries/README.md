# CLI Data Entry App

This is a simple Python command line app that lets a user enter movie data.

It:
- shows example movie data
- asks the user to enter new movie information
- lets the user confirm the entry
- allows more than one entry
- saves the data to a JSON file

## How to run it

First install Rich:

pip3 install rich

Then run the script:

python3 cli_data_entry.py

## Output

The data is saved in:

movie_data.json

# Fandom Wiki Scraping Assignment

For this assignment, I chose the Terraria Wiki on Fandom.

I decided to scrape the NPC category page and collect information from the pages linked there. My script gathers the NPC name, the page link, the links found on each NPC page, and the total number of links on each page.

I chose this wiki because Terraria is a popular game with a large fan community, and the wiki has a lot of organized information. I was interested in seeing how NPC pages are connected to other pages across the site. Looking at the number of links on each page can show which NPCs have more detailed or more connected entries.

I think this data could be useful to researchers because it shows how fan communities organize knowledge in a wiki format. It can also help researchers study which topics or characters are more developed and how information is linked together across pages.
